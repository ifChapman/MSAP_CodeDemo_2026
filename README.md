Data in this repository is from a single miniscope recording of piriform cortex neurons during freely moving cage exploration. 
Files included are the following:

miniscope_traces.csv --- activity of the neurons during the session, 2 dimensions (Neurons x Time)

event_times.csv --- timepoint where bedding was added to the cage, unit is milliseconds

miniscope_timestamps.csv --- time when each frame was captured by the miniscope

miniscope_metaData.json --- imaging parameters of the miniscope (framerate, LED brightness, gain, etc.)
